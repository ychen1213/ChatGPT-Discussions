# AH53 三种几何表示与组合流程：实际验证说明

运行日期：2026-10-24（香港时间）。运行编号：`20261024_v2`。

**模型身份：基于 AH53 名义版图的合成工艺形貌，不是实测 AH53 重建。交付为独立验证项目，尚未接入原 MarkSimModeler。** 本次只研究材料占据的三维区域，不计算电磁场、FDTD、n/k 或光学对准偏差。

## 1. 先知道这次回答什么

我们用同一个三条纹母单元，研究弯曲侧壁、左右不同的圆肩、不平的顶面和沿线波动怎样保存。实验 A 比较三种独立保存方式；实验 B 检查把一种格式转换为另一种格式后增加了多少误差。屏幕上看见三角形，不等于底层数据就是三角网格：参数化数据也需要临时三角化后才能显示。

已实际完成 A 的 9 组、B 的 4 条局部路径、1 条全域 P→T 路径和一次局部编辑。局部细档的双向截面距离 P95 分别为 P 0.01503 nm、T_direct 0.4339 nm、5 nm 体素 2.367 nm。这里的指标是规定截面的距离，不能解释成完整三维曲面的全域误差上界。

## 2. 为什么这是 16 µm 母周期 AH53

X 是条纹横向，Y 是高度，Z 是条纹长度。所有数值计算和保存坐标用 nm，图与查看器中按标注换算为 µm。原 Modeler 的 GDS 平面坐标为 X/Y、厚度沿 Z；本项目显式转换坐标含义，不能把两个工程的同名轴直接混用。

| 量 | 本轮值 | 身份 |
|---|---:|---|
| 母周期 | 16 µm | 已确认名义尺寸 |
| 三条纹中心 | −3.2、0、3.2 µm | 已确认名义尺寸 |
| 每条宽度／名义高度 | 1.6 µm／300 nm | 已确认名义尺寸 |
| 条纹区／相邻条纹区空白 | 8 µm／8 µm | 名义版图定义 |
| 局部场景 | 16×4 µm | 验证窗口 |
| 完整规模场景 | 48×48 µm，9 条纹 | 验证假设，非完整实测尺寸 |

母单元 X∈[−8,8] µm，三条纹分别占 [−4,−2.4]、[−0.8,0.8]、[2.4,4] µm。条纹之间的两段内部空隙也是 1.6 µm。单元左右各留 4 µm 空白，相邻单元连接后形成 8 µm 空白。3.2 µm 只是子光栅间距，不能拿它重复整个 AH53。

![名义布局](results/20261024_v2/figures/01_nominal_layout.png)

图中横轴 X、纵轴 Z，单位 µm；青绿色为三条条纹，灰色虚线中 X=±8 µm 是母单元边界，X=±4 µm 是条纹区边界。应观察三条纹成组以及组间较宽空白。

来源核查：本机 `MarkSimModeler/examples/AH53_DEMO/process.yaml` 与 GDS `AH53.gds` 的三条纹一致；GDS 顶层 `AH53_MARK` 包围盒为 [−4,−1]～[4,1] µm，共 3 个多边形。它是演示工程，不能把其中 2 µm 的示例长度当作真实完整 Mark 长度。路径、SHA256、计划书版本记录在 `inputs/source_provenance.json`。

局部模型和全域模型用相同全局坐标、母单元编号和条纹编号，局部是全域的裁片。扰动不随窗口大小重新抽样，不同母单元的名义图案重复而扰动不同。有限 Z 端面是人为封口，不纳入自由表面形貌误差。

## 3. 从理想到不规则形貌

宽度的控制平面是 Y=150 nm。左右侧壁的平均倾斜不同，并叠加平滑弯曲；靠近顶部的圆肩连接侧壁和顶面。顶面横向弯曲、沿 Z 高度起伏。中心线波动使两边共同移动；线宽波动使两边的间距改变；高度相关残差使 30、150、270 nm 平面上的边缘曲线不同。

配置使用随机相位有限傅里叶叠加：最短波长 160 nm，幅值按无限域理论 RMS 归一化，有限窗口重新测量。左／右圆肩特征尺度 [40, 70] nm、变化约 ±15%；顶部横向拱高 10 nm。中央母单元的中间条纹在 Z=400 nm 有局部连续挑战：沿线半高宽 180 nm、左侧位移幅度 18 nm、顶部增加 12 nm。圆肩由与两侧共享端点、对齐切线方向（G1 几何光顺）的解析 Bézier 段定义；参考生成器不调用候选样条。

![理想与合成截面对照](results/20261024_v2/figures/02_cross_sections.png)

横轴为相对条纹中心的 X，纵轴为真实高度 Y，单位 nm。虚线为 1.6 µm×300 nm 理想矩形；不同颜色表示同一已保存参考在不同 Z 位置的截面。观察左右不对称、顶部拱起和圆肩。坐标轴使用同一物理长度比例；若图局部放大，范围会在坐标轴上给出。

“RMS 6 nm”表示去除均值后位移的均方根，不是最大位移，也不是 3σ。相关尺度描述波动沿 Z 延续多远，不是条纹周期。最短随机波长限定保留的细节；连续局部凸凹另外定义。本轮的圆肩尺度、粗糙幅度、相关尺度都是工程假设，不能作为 AH53 实测参数引用。

随机场的定义是固定波长 λ、谱权重 w 与独立均匀随机相位的正弦和；其归一化集合相关函数为 `ρ(ΔZ)=Σ w² cos(2πΔZ/λ) / Σ w²`。配置中完整列出波长和权重。它包含短、长两类尺度，没有把“0.3 µm、2 µm”声称为经过拟合的两个唯一高斯相关长度。局部高斯凸凹另有明确半高宽，不混同随机场的最短波长。

## 4. 实验 A 与实验 B 回答不同问题

实验 A：参考形貌→共同的有序观测轮廓→分别建立 P 与 T_direct；参考形貌另一路直接产生 V_direct。局部三种表示各粗、细一档，再加全域三种表示各一档，共九组。

| 数据 | 真实保存内容 | 重新读取后怎样查询 |
|---|---|---|
| P 参数化 | 分段轮廓的样条系数、节点、有效 Z 域和材料编号 | 从保存的参数计算轮廓和材料区间 |
| T_direct 直接三角面 | 从共同观测点得到的顶点、面片连接和结构索引 | 与保存的实际三角面求交 |
| V_direct 直接体素 | `uint8` 材料标签、原点、间距、轴序 | 读取对应单元标签；边界来自标签切换 |

P 与 T_direct 得到完全相同的观测轮廓，T_direct 不读取 P 的系数。V_direct 可以直接查询连续参考，具有更多输入信息；它反映直接体素化的离散下限，**不能据此把 A 的三者排列为同样稀疏实测条件下的重建优劣**。

本轮参数化采用分段轮廓的数值组织方式。单对左右边界在每个 Y、Z 处材料为一个区间时可以表达圆肩和圆顶；圆顶顶部 X(Y) 的导数变大，均匀高度样条可能需要密集节点。沿轮廓参数行走便于处理这一端点数值问题。这是实现选择，不是证明左右边界表达能力不足。此合成对象保留单横向区间；两个分离峰导致同一高度出现多个材料区间时，需要区间列表或更一般的数据模型。

实验 B 从已保存并重新读取的数据开始：

```text
同一有序观测轮廓 ──→ T_direct ─────────→ V_from_Tdirect  [B4]
        │
        └─→ P ────────────────→ V_from_P              [B2]
             └─→ T_from_P [B1] ──→ V_from_T           [B3]
```

三条最终体素路径使用相同原点、5 nm 单元、坐标轴序和材料编号。来源哈希、输入观测编号和转换参数见 `lineage.json`。T_from_P 继承拟合误差；T_direct 仅继承观测离散和放样误差。两者都是有效三角表面，来源不同。

## 5. 怎样理解“总误差”和“新增误差”

总误差比较输出与共同参考；新增误差比较输出与它自己的上游。例如 B1 比较 T_from_P 与参考得到总误差，再比较 T_from_P 与 P 得到三角化新增误差。二者使用相同物理距离定义。不能将各步 RMS 或 P95 相加：偏移方向可能抵消，统计量也不具可加性。

![圆肩局部比较](results/20261024_v2/figures/03_shoulder_comparison.png)

横纵轴分别为 X 与 Y，单位 nm，显示未用于构建的同一 Z 截面。颜色区分参考、P、T_direct、T_from_P 和原始体素。观察圆肩的连续转向、三角面的折线、体素的水平／竖直台阶。折线不是把稀疏点云最近邻误差当作曲面误差：评价使用实际线段的距离。

## 6. 指标、评价误差与适用范围

本次主边界指标明确采用**双向、按弧长加权的 XY 截面点到实际线段距离**。局部取 Z=−1783、−1167、−443、137、413、677、1549 nm，全域另取 8 个指定截面，覆盖中央局部起伏。这些位置不在 40/80 nm 构建节点上。分别报告左壁、左圆肩、顶面、右圆肩、右壁，底面和人工 Z 封口不参与主指标。参考和 P 评价轮廓以约 1 nm 几何步长离散，三角面按实际面片相交，体素按实际标签边界求交；距离计算投影到实际线段，不是稀疏顶点最近邻。两方向分别保存，统计采样步长约 2 nm。

| 指标 | 初学者的理解 |
|---|---|
| RMS | 典型偏差；先平方平均再开方 |
| P95 | 95% 的指定加权采样距离不超过该值；不是全域上界 |
| 采样最大值 | 本次采样看到的最大偏差，不等于精确 Hausdorff 距离 |
| CD | 同一个真实 Y、Z 处右边缘减左边缘 |
| 几何中心 | 同一处左右边缘的平均值，不是光学 Alignment/OVL 偏差 |
| 近界面错分率 | 固定物理宽度边界带中，材料标签不同的比例 |
| 全域错分率 | 整个包围盒抽样的错分比例，容易被大片空气稀释 |
| 数据负载／文件字节 | 前者是实际数值数组，后者包含格式开销；不等于峰值内存 |

CD 和中心在共同物理高度 Y=30、150、270 nm 测量，不能各自按模型高度归一化后比较。无交点时记为缺失或几何失败，不悄悄丢弃。体素原始法向都是轴向，不能用逐面法向角与光滑曲面直接排名。

1 nm P95 观察线只是可配置工程目标，不是用户工艺合格线。有限 4 µm 长度对长相关尺度的统计能力有限，长尺度边缘曲线用完整 48 µm 场景补充。

在中央条纹 Z=413、677 nm 处，将参考轮廓步长由 1 nm 加密到 0.25 nm，实测截面距离的最大差异为 0.0013293 nm。这是本次高曲率处的数值收敛证据，不是全域解析上界；它也限定了极小误差的可解释精度。

## 12. 怎样操作 3D View

双击项目根目录 `启动3D查看器.bat`。它使用本项目 Python 环境，在 `127.0.0.1` 启动服务并打开浏览器。Three.js 和页面全部在本地目录，不依赖 CDN，不要求运行时安装 Node.js。不要直接双击 `viewer/index.html` 代替启动器，因为模型和截面需要本地服务。

1. 先用“整个 Mark”看九条纹，再选“单母周期”“单条纹”“局部圆肩”。
2. 在“实验 A”里依次切换参数化、直接三角面和直接体素；选择“实验 B”后查看 B1～B4 的来源与目标。
3. 用正交投影核对尺寸；俯视看 XZ 排布，XY 方向看截面。旋转拖动、滚轮缩放、右键平移。
4. 拖动 Z 控件更新真实 XY 截面，改变 Y 更新 XZ 等高截面；打开叠加查看相同位置的轮廓。
5. 局部开启线框，体素观察台阶；隐藏衬底可看到接触边界。高度放大只影响显示，页面持续显示倍率。
6. 用重置相机恢复视角，保存截图，最后打开详细说明。

![查看器实际截图](results/20261024_v2/figures/viewer_screenshot.png)

真实 XY 截面是几何与 Z=常数平面的交线；真实 XZ 等高截面是 Y=常数的材料分区。它们从选定的实际模型计算。仅把外表面隐藏一半不会自动产生这样的材料截面。

已在真实 Chromium 浏览器的 950×680 窗口完成连续操作：全域→母单元→单条纹→A 三种实际表示→B1 参数导出面→圆肩叠加→Z=410 nm 的 XY 截面→Y=270 nm 的 XZ 截面→B2/B3/B4 各体素→隐藏衬底、线框、平面着色、倍率切换→重置→保存截图→打开详细说明。旋转、缩放和平移已实际操作，模型切换保持相机位置；页面没有横向溢出、最终流程没有 JavaScript 异常，文档图片均加载成功。左侧面板在小窗口独立滚动。

全域 P 首次加载约 8.65 s，缓存后一次实测约 1.98 s。一次短时全域渲染采样的帧间隔中位数约 16.7 ms、P95 约 16.8 ms；这不是所有机器或所有操作的帧率承诺。细体素单条纹包含 389,684 个原始面片，选择到截面全部就绪约 10 s；圆肩局部切换通常较快。加载阶段会显示状态，不能把本轮说成所有操作瞬时完成。

已核对中文及空格路径、端口占用自动换端口和缺失环境的恢复提示，证据见 `viewer_backend_checks.json`。完整预览显示精度单列：P 抽样截面最大偏差约 1.48 nm；体素全域简化预览约 25 nm，因此纳米细节必须使用局部原始边界，不能用全域预览代替正式误差。两个数都是指定预览截面的抽样证据。

## 13. 怎样识别几何问题

1. 在圆肩预设中切换 P、T_direct 和 T_from_P，查看弧线是否变成尖角、是否出现接缝或不合理折返。
2. 保持同一 Z，叠加参考截面。侧壁不能只剩连接上下端点的一条直线；顶部也不应被固定在 300 nm 的水平线上。
3. 改变 Y，观察不同高度处边缘是否变化。若三条曲线只是完全一样的平移，可能丢了高度相关扰动。
4. 选择体素局部原始边界，台阶就是实际材料格子的边界；它不会因为平滑渲染而消失。屏幕上放大高度时注意持续显示的倍率。
5. 观察来源详情。T_direct 应源于有序观测轮廓；T_from_P 应源于保存的 P；各体素应有不同上游哈希。

## 14. 最终系统该保存什么

本轮局部细档 P 使用 2.118 MB 数值负载，T_direct 使用 6.244 MB，5 nm 体素使用 256 MB。结合各自误差和编辑记录，建议对于本轮这类分段光滑、固定拓扑且需要语义编辑的模型，保留原始观测并以 P 作为可编辑源，按用途派生三角面和体素；如果来源本身就是经配准的实测轮廓或外部三角网格，也允许 T_direct 作为独立主数据，不强制反拟合参数。

不要将一次合成结果硬编码成唯一格式。保留来源类型、实际连接和材料域，让两种源数据可并存；派生输出带参数与哈希，可失效后重建。原始体素适合直接材料查询和离散接口，但单元量化会改变边界，存储随分辨率增长快；是否保留全部缓存由实测资源和使用频率决定。

无论最终选择哪一类主数据，都应保留材料编号、单位、坐标约定、原始观测与位置、变换历史和来源哈希。只保存漂亮的轻量预览会丢掉可重复查询所需的信息。

## 15. 怎样修改参数和重跑

配置入口是 `configs/default.json`，名义尺寸、合成假设、密度和预算分开记录。修改之前复制一份配置。例如把 `synthetic.shoulder_scale_nm` 从 `[40,70]` 改为 `[45,70]`，表示改变合成参考的左圆肩尺度；这不是更改真实工艺测量。已有模型不会随配置文件自动变化，需要重新构建。

在项目目录打开 PowerShell：

```powershell
.\.venv\Scripts\python.exe run_validation.py --help
.\.venv\Scripts\python.exe scripts\build_report.py --help
```

完整重跑示例（使用新目录）：

```powershell
.\.venv\Scripts\python.exe run_validation.py --config configs/default.json --output results/new_run
.\.venv\Scripts\python.exe scripts/audit_saved_results.py --output results/new_run
.\.venv\Scripts\python.exe scripts/build_report.py --run new_run
```

改完配置后用新的输出目录，保留旧模型与结果。默认执行一次规定的九组和四条路径；没有达到 1 nm 观察目标会如实报告，不自动无限加密。

## 16. 将来怎样替换成实测

每条观测轮廓必须知道条纹编号、所在 Z、X/Y 坐标、单位、材料标识和边界行走顺序。不同截面的点需要建立对应关系；圆肩、侧壁、顶面的分段位置应连续。要同时保留测量不确定度、仪器分辨率和配准误差，不能把它们记作算法误差。

单张 SEM/TEM 截面不能唯一确定全三维形貌。沿线相关性、不同高度关联和局部异常的位置需要额外数据或明确假设。若实际轮廓在同一高度出现多个分离材料区间，不能用最外侧边缘直接填满中间空气，必须升级存在域表示。这轮不涵盖小孔、airgap、桥接和拓扑变化。

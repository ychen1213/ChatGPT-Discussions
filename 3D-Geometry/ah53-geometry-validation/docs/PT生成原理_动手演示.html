同样四组截面点，
P 和 T 怎样连出不同的形状？

先只看条纹的一个高度：Y = 150 nm。沿长度 Z 选四个位置，记录每处的左边界和右边界。P 用光滑函数连接；这个简化例子中的 T 用直线段连接。

本页用来理解原理。长度只取 Z = 0～600 nm，宽度以 1600 nm 为基准。这些数字是教学设定，不是 AH53 的误差实验结果，也不用于给 P、T 排名。本页展示的是固定高度上的边界轨迹；完整三维表面还要包含其他高度。

1. 先造一条会变化的条纹

把条纹想成一条道路：中心 c 决定道路往左还是往右偏，宽度 w 决定道路变宽还是变窄。于是左右边界可以写成：

xL(Z) = c(Z) − w(Z)/2
xR(Z) = c(Z) + w(Z)/2

本页让变化从两端的 0 平滑增加到中间最大，再回到 0：

q = Z / 600，s = 4q(1−q)
c(Z) = A·s，w(Z) = 1600 + B·s

A 是中间位置的中心偏移量；B 是中间位置的完整宽度增加量，不是单侧增加量。两端 s = 0，中间 Z = 300 nm 时 s = 1。

正数向 +X 偏，负数向 −X 偏。

正数变宽，负数变窄；两边各分担一半。

它与“基准边界 + 空间变化场”的公式是什么关系？

在本页固定的 Y = 150 nm 高度，基准左边界是 −800 nm，基准右边界是 +800 nm。你的公式在这里具体变成：

xL = −800 + uL，xR = +800 + uR
uL = c − (w−1600)/2 = (A−B/2)·s
uR = c + (w−1600)/2 = (A+B/2)·s

因此左右变化场不是另一种神秘结构：它们就是每个位置相对基准边界的位移。两侧同向等量移动只改变中心；两侧反向移动会改变宽度。完整模型中的 u 还可以随高度 Y 变化，本页暂时把 Y 固定住。

2. 只留下四个截面的观测点，再分别重建

取点在 Z = 0、200、400、600 nm 记录左右边界。
生成 P从这四组坐标计算光滑插值函数，查询时计算函数值。
生成 T 的轨迹同一侧相邻观测点用直线相连，查询时在该线段上取值。

P 的教学版：给定四个 Z 值和对应的左边界值，用四点 Lagrange 插值计算唯一的至多三次多项式；右边界同样处理。程序先保存这四个样本，之后 P 的查询只使用样本。

P(Z) = Σi=0…3 xi · ℓi(Z)
ℓi(Z) = ∏j≠i (Z−Zj)/(Zi−Zj)

本页造数据的 s 是二次多项式，所以四点插值刚好能恢复它。这里的 P 与无内部结点、经过这四点的三次样条给出相同结果；这只是完整 P 方法中一个很简单的特例。实际项目使用分区轮廓的二维张量积三次样条，并不只存四个点，也不使用一条全局多项式处理整个大 Mark。

T 的教学版轨迹：找到包围当前位置的两个观测截面 Zi、Zi+1，计算当前位置走到了这段距离的几成，再按这个比例混合两个端点。

t = (Z−Zi)/(Zi+1−Zi)
T(Z) = (1−t)·xi + t·xi+1

完整 T 保存的是三维顶点和三角形连接关系，表面由平面三角形组成。本页特意只观察一条沿 Z 的顶点轨迹，所以可以直接画成分段直线。完整三角网格在任意高度切开后，通常需要计算平面与三角形的交线，不能一律套用这里“两点之间直线插值”的简化公式。

为什么观测点处相同，中间却可以不同？

因为共同输入只告诉我们“这四处在哪里”，没有把它们之间的所有位置都告诉我们。两种方法都忠实经过样本，但采用了不同的连接规则：P 用平滑函数，T 用平面片组成表面；本例考察的轨迹因此是直线段。

这不是 P 多读了参考答案：本页 P 的插值同样只读这四组点。但教学参考恰好是一个光滑二次函数，恰好能被所用插值精确重建。若实物有尖角、噪声或两点之间隐藏着缺陷，不能据本页认定 P 一定更准确。

4. 从这张二维图回到三维

刚才固定了 Y，只看这一高度的左右边界。现在想象：把这一套描述扩展到其他高度，低处、中间、圆肩、顶部都有各自的边界；再沿所有 Z 位置铺开，便得到整条条纹的外表面。

P 保存连续表面的函数及其系数。想知道某个位置在哪里，就代入参数计算。T 保存离散顶点和连接这些顶点的三角形。相邻截面的对应点连接成网带，每个四边形通常拆成两个三角形，再封闭必要的底面与端面。

“参数化截面、扫掠、空间变化场”是在说明形状如何随空间变化；“P 或 T”是在说明最终如何保存和计算这个形状。二者属于不同层面：同一个随位置变化的截面方案，既能生成 P，也能采样生成 T。

```text
D:\工作\ChatGPT-Discussions\3D-Geometry\ah53-geometry-validation\results\20261024_v2\models\
```

复制到 Windows 文件资源管理器地址栏即可找到。`local_P_fine` 是局部参数化模型，`local_T_direct_fine` 是局部三角表面，`local_V_direct_fine` 是局部 5 nm 体素；完整范围以 `full` 开头。每个子目录是一套数据，移动时保留整套；目前不是 STL/OBJ/STEP 格式。

**从 GitHub 刚下载？** 仓库有代码、图片、结果表、报告和小样；完整大模型与 Python 环境保留本机。请按 [README 重建步骤](README.md) 生成完整模型后再启动。只读教程和检查小样不需要重建全部模型。

这是**基于 AH53 名义版图的合成工艺形貌**验证项目，不是实测重建；本轮没有运行 FDTD，也没有修改原 Modeler。

1. **双击 `启动3D查看器.bat`。** 保持启动窗口打开，浏览器会连接本机服务。当前计算机的项目 Python 环境已准备好；运行时不需要网络或 Node.js。
2. 默认打开完整 **48×48 µm、三个 16 µm 母周期、九条纹**的已保存参数化模型。完整尺寸是计划书的验证假设。顶部“全域简化预览”用于定位，细节请进入“单条纹”或“局部圆肩”。
3. “实验 / 转换路线”选 **A**，在“实际数据 / 表示”中切换参数化、直接三角面、直接体素。也可以选 **B1～B4**，核对不同转换路径的实际结果。局部场景提供粗／细两档。
4. 选择“局部圆肩”，用“沿条纹看 XY”与“正交”放大顶角。拖动 **Z** 更新真实 XY 截面；改变 **Y** 查看不同高度处的 XZ 边缘波动。勾选叠加可在同一位置比较参考、直接面与参数化导出面。
5. 左键拖动旋转、滚轮缩放、右键平移。默认高度比例为 **1×**；可以临时放大，并注意画面持续显示的倍数。隐藏衬底、开线框后可核对边界；“重置视角”恢复视图。
6. “保存截图”会保存图像和来源 JSON 到当前结果的 `figures/screenshots/`。窄窗口下左侧控制面板可以独立滚动，底部还有截面、截图和来源详情。

**详细说明：** 双击 `AH53_三种几何表示验证_详细说明.html`，无需本地服务或 Markdown 编辑器；同名 `.md` 内容一致，便于归档或交给其他 AI。

**结果：** `results/20261024_v2/metrics.csv` 是实验 A 九组；`conversions.csv` 是四条局部转换与一条全域转换。分区、材料错分、体积、CD、中心和边缘频谱见 `details/`。实际模型在 `models/`，来源关系在 `lineage.json`，局部编辑在 `edit_check.md`。

**改参数：** `configs/default.json`。改动不会自动改变已保存结果；按详细说明用新输出目录重跑。源代码和结果是独立项目，未接入原 Modeler。

**小型检查样例：** [samples/README.md](samples/README.md) 解释实际保存的参数、三角连接和 5 nm 标签裁片；[约 1 MB 的样例压缩包](samples/AH53_实际模型小样.zip) 可单独归档。

遇到启动问题：

- **不要直接双击 `viewer/index.html`。** 页面读取模型和计算截面需要启动器提供的本地服务。
- **窗口报找不到环境或依赖：** 按窗口给出的命令恢复 `.venv`。首次安装需要 Python 和网络；恢复完成后可离线使用。环境不是可跨电脑直接搬运的便携 Python。
- **页面空白或连接失败：** 确认启动窗口仍开着，使用窗口打印的 `127.0.0.1` 地址；默认端口占用时会自动改用空闲端口。页面会显示模型加载错误，不要把长时间“正在加载”当作成功。

文件夹含中文、空格均可使用。保留完整项目目录及结果图像，离线 HTML 中的相对图片链接才能正常显示。

# 讨论记录：AH53 Mark 的 FDTD 与 RCWA 仿真流程比较

**用户：**

对于FDTD来说 我要仿真和RCWA同样的一个AH53mark结构 仿真过程会有什么不同吗 需要注意的事项有什么呢

**助手：**

对于你目前的 AH53 Mark，如果使用 FDTD 仿真与 RCWA 完全相同的结构，**最终求解的物理问题是一样的，但建模方法、数值计算过程、计算量，以及结果提取方式都有明显区别。**

尤其需要注意：你的目标不仅是得到反射率 \(R\) 和各阶衍射效率，还要得到用于 SMASH 光路计算的复振幅 \(r_{ss},r_{sp},r_{ps},r_{pp}\)，包括相位信息。因此，FDTD 对监视器位置、相位参考面和归一化的要求会更高。

## 一、先明确：AH53 的 RCWA 和 FDTD 应该使用什么模型？

按照你之前采用的 AH53 二维模型，参数如下。

| 参数 | 数值 |
|---|---|
| 母周期 \(P\) | 16 μm |
| 子光栅中心间距 | 3.2 μm |
| 每个母周期的条纹数量 | 3 条 |
| 条纹中心位置 | −3.2、0、+3.2 μm |
| CD（条纹宽度） | 1.6 μm |
| 条纹高度 | 300 nm |
| 入射波长 | 643 nm |
| 入射方向 | 沿 −Y，法向入射 |
| 示例材料 | 空气 n=1、衬底 n=1.5、条纹 n=2.0 |
| 仿真维度 | XY 二维，Z 方向结构均匀 |

材料折射率只是此前的测试示例，实际比较时应以你的 RCWA 文件中的材料和膜层为准。

这个结构的关键在于：**周期边界必须使用 16 μm，而不是 3.2 μm。** 因为整个 AH53 单元并非每 3.2 μm 重复一次，而是每 16 μm 才完整重复。

## 二、RCWA 和 FDTD 在仿真过程上的区别

| 对比项目 | RCWA | FDTD |
|---|---|---|
| 计算原理 | 将介电常数和电磁场展开为傅里叶谐波，求解各层之间的模式耦合 | 在空间网格上逐时间步求解麦克斯韦方程 |
| 结构表达 | 定义周期、层叠和横向形貌 | 定义实际二维几何与材料分布 |
| 精度控制 | 主要调节傅里叶阶数、分层数 | 主要调节网格尺寸、时间收敛和边界条件 |
| 光源 | 用频域平面波激励 | 用时域脉冲激励，再提取 643 nm 频率分量 |
| 边界 | 周期性由傅里叶展开处理 | 必须显式设置 Periodic/Bloch 和 PML |
| 输出 | 直接获得各阶衍射参数及复数 S 参数 | 先获得时域场和频域场，再进行空间傅里叶分解 |
| 计算速度 | 对规则周期层状结构通常更快 | 通常更慢，尤其是高分辨率及三维模型 |

Ansys 官方文档也指出，对规则周期结构，RCWA 通常比 FDTD 更高效；FDTD 的优势主要体现在非周期结构、复杂实际形貌及更广泛的激励条件。<Cite refs={["turn970827search13","turn970827search15"]}/>

对你来说，可以将两者理解为：

RCWA：

\[
\text{几何结构}\rightarrow
\varepsilon_m\rightarrow
\text{傅里叶模式耦合}\rightarrow
r_m
\]

FDTD：

\[
\text{几何结构}\rightarrow
\text{空间网格}\rightarrow
E(x,y,t),H(x,y,t)
\]

\[
\rightarrow E(x,y,\omega)
\rightarrow\text{衍射级分解}
\rightarrow r_m
\]

因此，你在 RCWA 中通常直接看到的各阶复振幅，在 FDTD 中往往需要额外的数据处理才能获得。

## 三、AH53 的 FDTD 具体应该怎样设置？

以下以 Lumerical FDTD 2023 R2.1 的二维模型为例。

**建议的初始设置**

| 参数 | 设置 |
|---|---|
| Simulation dimension | 2D（XY） |
| X min / max | −8 / +8 μm |
| Y min / max | −1.2 / +1.8 μm |
| X boundaries | Periodic / Periodic |
| Y boundaries | PML / PML |
| Source | Plane wave，沿 −Y 入射 |
| Wavelength | 先采用 640–646 nm，读取 643 nm |
| Polarization | 分别运行 s、p 两次 |
| Initial mesh | 关键结构区域 dx≈20 nm、dy≈15 nm |

以上为第一轮调试设置，不代表最终收敛参数。Y 方向计算域需要根据真实堆膜、监视器和 PML 间距调整。

### 1. 边界条件：不要全部设成 PML

对于严格复现 RCWA 的 AH53 周期模型：

- X 方向使用 Periodic。
- Y 方向使用 PML。
- Z 方向没有实际计算边界，因为模型是二维。

这样，FDTD 就相当于在 X 方向无限复制这个 16 μm 的 AH53 单元。

法向入射时，Periodic 可以满足电磁场的周期性；以后研究斜入射时，通常需要改用 Bloch 边界，让相邻周期之间具有正确的相位差。<Cite refs={["turn970827search0","turn970827search2"]}/>

### 2. 偏振设置：注意 Lumerical 的二维命名

在你的 XY 模型中：

| 光学偏振 | 电场方向 | Lumerical 二维场模式 |
|---|---|---|
| s 偏振 | \(E_z\) | TM：\(E_z,H_x,H_y\) |
| p 偏振 | \(E_x,E_y\) | TE：\(E_x,E_y,H_z\) |

这里容易出现术语混淆：Lumerical 的二维 TE/TM 命名是相对于不变的 Z 轴定义的，不应直接拿它当作光学入射面的 s/p 命名。<Cite ref="turn970827search15"/>

因此，想得到完整 Jones 矩阵时，需要分别运行 s、p 入射，再将得到的出射场投影到 s、p 偏振基底。

对于理想二维、各向同性且没有锥形入射的 AH53 结构，理论上交叉偏振系数 \(r_{sp}\)、\(r_{ps}\) 为零。初期验证时应重点比较 \(r_{ss}\) 和 \(r_{pp}\)。

### 3. 监视器的位置：这是 FDTD 与 RCWA 最容易产生差异的地方

对于 AH53，建议先采用下面的布置。坐标仅作为初始示例。

```text
Y = +1.8 μm  ───── 上方 PML

Y = +1.35 μm ───── R monitor（反射场）
                         ↑ 反射光

Y = +1.00 μm ───── Plane wave source
                         ↓ 入射光

Y = +0.30 μm       ┌────┐  ┌────┐  ┌────┐
                   │    │  │    │  │    │
Y =  0.00 μm ──────┴────┴──┴────┴──┴────┴───
                   衬底 n = 1.5

Y = -0.80 μm ───── T monitor（透射场）

Y = -1.20 μm ───── 下方 PML

X = -8 μm       ← 16 μm →       X = +8 μm
   Periodic                           Periodic
```

除了 R、T 功率监视器，建议增加一个 XY 场分布监视器，用来观察光栅附近的 \(E\) 场分布。

这里要注意三件事。

**首先，反射监视器应当处于均匀介质中。** 不能让 R monitor 穿过上方堆膜，否则普通的 grating projection 可能无法正确解释反射衍射级。Ansys 官方的 FDTD 光栅示例也特别强调这个条件。<Cite ref="turn584774view0"/>

**其次，要分清入射场和反射场。** 按上图将 R monitor 放在向下入射的单向平面波光源上方，通常可以直接记录向上传播的反射场。如果将监视器放在光源和光栅之间，记录的是入射场与反射场的叠加，需要利用参考仿真分离入射分量。

**最后，如果需要比较相位，监视器位置不能随意改变。** 即使改变 R monitor 的 Y 坐标不应改变正确计算的衍射效率，也会改变各阶复电场的传播相位。

## 四、怎样在 FDTD 中提取与 RCWA 一样的衍射结果？

这是你后续光路仿真需要重点解决的问题。

### 1. 衍射级数和出射角

与 RCWA 一样，周期 \(P=16\ \mu m\) 决定了离散的衍射方向。

法向入射、空气侧反射时：

\[
\sin\theta_m=\frac{m\lambda}{P}
\]

由于 \(\lambda=0.643\ \mu m\)，有：

\[
|m|\leq \left\lfloor\frac{16}{0.643}\right\rfloor=24
\]

也就是说，在空气侧理论上有 **49 个可传播反射级次**（从 −24 到 +24）。

例如：

| 衍射级 m | 出射角绝对值 |
|---|---:|
| ±1 | 2.30° |
| ±5 | 11.59° |
| ±10 | 23.70° |
| ±14 | 34.24° |
| ±24 | 74.69° |

其中 ±5 阶值得关注，因为条纹中心间距为 3.2 μm，满足 \(16/3.2=5\)。它对应子光栅周期的一级衍射方向，但由于每个母周期只有三条条纹，其他母周期衍射级仍可能存在。

如果你之前提到的 NA=0.6 是反射侧空气中的收光 NA，在法向入射模型里，理想孔径只能收集 \(|m|\leq14\) 的传播级次。

### 2. 如何获得各阶衍射功率？

你已经使用过的命令可以继续使用：

```javascript
mon = "R";

f = getdata(mon,"f");
fi = find(c/f*1e9,643);

N = gratingn(mon,fi);
theta = gratingangle(mon,fi);
G = grating(mon,fi);

Rtotal = abs(transmission(mon));
Rm = G*Rtotal;
```

这里：

\[
G_m=\frac{R_m}{R_{\mathrm{total}}}
\]

所以：

\[
\boxed{R_m=G_mR_{\mathrm{total}}}
\]

这与 RCWA 返回的以入射功率归一化的 `grating_power` 是可以直接比较的物理量。`grating()` 本身返回的是各传播级在总反射或总透射功率中的相对占比。<Cite ref="turn970827search1"/>

### 3. 如何获得各阶复振幅？

这里就比提取功率复杂了。

你之前用过：

```javascript
V = pinch(gratingvector("R",fi));

ip = find(N,1);
im = find(N,-1);

Ep = V(ip,3);
Em = V(im,3);
```

对于 s 偏振，`V(ip,3)` 对应 +1 阶的 \(E_z\) 相关复数分量。用它分析同一配置下的相对相位变化很方便。

但注意，**`gratingvector()` 的结果不是直接以入射电场为基准归一化的绝对反射复振幅 \(r_m\)。**

根据 Ansys 文档，它满足：

\[
\sum_m\left(
|V_{x,m}|^2+|V_{y,m}|^2+|V_{z,m}|^2
\right)=1
\]

这是所有传播级之间的相对归一化。<Cite ref="turn970827search8"/>

因此，要和 RCWA 比较真正的反射 Jones 矩阵，必须先统一归一化和相位参考面。

### 4. 最推荐的复振幅提取方式

对反射监视器得到的频域场 \(E_z^{\mathrm{ref}}(x,y_R)\) 进行空间傅里叶分解：

\[
\boxed{
A_{m,s}^{R}(y_R)=
\frac{1}{P}
\int_{-P/2}^{P/2}
E_z^{\mathrm{ref}}(x,y_R)
e^{-i2\pi mx/P}\,dx
}
\]

这个公式用于 s 偏振、法向入射的 AH53。

它所做的事情很直观：将 FDTD 计算得到的反射电场，分解为周期 16 μm 对应的不同空间频率，每一个空间频率对应一个衍射级次。

对于 p 偏振，则需要使用 \(E_x,E_y\) 并投影到各阶 p 偏振单位矢量上。

然后把每个 \(A_m^R\) 的相位传播回与 RCWA 相同的参考面，再除以该参考面的入射电场复振幅：

\[
\boxed{
r_m=\frac{A_m^R(y_0)}{A_{\mathrm{inc}}(y_0)}
}
\]

其中 \(y_0\) 是双方约定的共同参考面。

假设使用 \(e^{-i\omega t}\) 的相位约定，反射光在 Y 方向传播的波数为 \(k_{y,m}^{R}\)，则：

\[
A_m^R(y_0)=A_m^R(y_R)
e^{-ik_{y,m}^{R}(y_R-y_0)}
\]

这一步是在进行**相位去嵌入（phase de-embedding）**。

对于未来要计算 SMASH 干涉信号的应用，这一步不能省略，否则由于不同阶次的传播角不同，各阶可能引入不同的额外相位。

### 5. RCWA 的 S 参数也需要统一归一化

Lumerical RCWA 的 `grating_characterization` 输出复数 S 参数，它们是功率归一化的复数系数，不一定直接等于电场幅值反射系数。

对于无损均匀入射及出射介质，若 \(r_m\) 定义为电场幅值比，则：

\[
\boxed{
R_m=
\frac{n_{\mathrm{out}}\cos\theta_m}
{n_{\mathrm{in}}\cos\theta_i}
|r_m|^2
}
\]

而 RCWA 的功率归一化系数满足：

\[
|S_m|^2=R_m
\]

因此，在当前空气侧法向入射的反射条件下：

\[
\boxed{
r_m=\frac{S_m}{\sqrt{\cos\theta_m}}
}
\]

该式默认偏振基矢和相位参考已经统一，且这里的 \(r_m\) 是电场矢量幅值系数。Ansys 官方的 RCWA 文档明确说明了 S 参数包含折射率和衍射角的功率归一化修正。<Cite ref="turn501928search2"/>

这也与你之前提出的要求对应：如果光路信号模型使用各阶电场复振幅的模平方，那么就应使用 \(|r_m|^2\)，不能不加区分地用 \(R_m\) 替代。

## 五、FDTD 最需要注意的几个数值问题

### 1. 网格不能只看光栅的 CD

对于你的 AH53，条纹 CD 为 1.6 μm，看起来比较大，但还要考虑高度 300 nm、材料中的有效波长以及层间界面。

如果条纹折射率为 \(n=2\)，材料内的波长为：

\[
\lambda_{\mathrm{medium}}=\frac{643}{2}=321.5\ \mathrm{nm}
\]

使用 20 nm 网格，材料内每个波长大约有 16 个网格点，适合初期验证，但并不能保证复振幅已经收敛。

建议做下面的网格测试：

| 测试 | dx | dy | 目的 |
|---|---:|---:|---|
| 粗网格 | 40 nm | 30 nm | 快速确认模型正常 |
| 中网格 | 20 nm | 15 nm | 初步计算各阶复振幅 |
| 细网格 | 10 nm | 7.5 nm | 验证幅度及相位收敛 |

这里不一定需要全域使用细网格。可以在条纹及膜层附近使用 Mesh Override，在均匀空气区和衬底内部使用较粗的非均匀网格。

对于约 16 μm × 3 μm 的二维计算域，如果全域采用 20 nm × 15 nm 均匀网格，大约有 16 万个空间网格单元（不包括 PML 等额外开销），计算规模并不特别大。

但如果网格尺寸同时减半，二维网格点数约增加 4 倍，时间步数也会增加，因此计算成本会明显上升。<Cite ref="turn501928search1"/>

### 2. PML 对高阶衍射可能产生明显影响

刚才已经算出，AH53 在空气侧最高可以出现 ±24 阶，出射角约 74.7°。

这意味着存在接近掠射方向的传播光。

普通 PML 对大角度入射光可能吸收不够理想，产生反射并返回计算区域。

建议先采用标准 PML 进行测试，再与 `Steep angle` PML 对照，并测试不同 PML 层数和位置。Ansys 的光栅示例也专门提出了这一点。<Cite ref="turn584774view0"/>

不要仅凭 R/T 能量接近 1 就断定结果正确，还需要检查不同 PML 设置下重要衍射级的复振幅是否稳定。

### 3. 仿真时间必须足够长

RCWA 是频域求解，不需要等待电磁场随时间衰减。

FDTD 则需要让入射脉冲传播、与结构相互作用，再等待残留电磁场充分衰减。

在 Lumerical 中，需要检查 `Simulation time` 和 `Auto shutoff`，确认不是在场还未充分衰减时便停止仿真。

你关注的是干涉相位，所以除了观察 \(R_{\mathrm{total}}\) 是否稳定，还应比较延长仿真时间后各阶复系数的变化。<Cite ref="turn343516view2"/>

### 4. 材料的 n、k 必须一致

如果 RCWA 直接使用材料在 643 nm 的复折射率：

\[
\tilde n(643\ \mathrm{nm})=n+ik
\]

FDTD 的材料色散模型则可能需要将材料数据拟合成适合时域计算的形式。

因此，即使使用同一个材料库，两个求解器实际采用的介电常数也可能存在细微差异。Ansys 将材料拟合和有限网格色散都列为 FDTD 数值误差来源。<Cite ref="turn501928search0"/>

建议初期优先用 \(n=1.5\)、\(n=2.0\) 这样的无损常数折射率验证算法，再引入实际的 \(n(\lambda),k(\lambda)\) 材料库。

### 5. 真实有限尺寸 Mark 和周期模型不是同一个问题

这是与你最终课题关系很大的一个区别。

当前使用：

\[
P=16\ \mu m,\qquad X:\mathrm{Periodic}
\]

模拟的是无限周期排列的 AH53 单元。

但你之前提到实际光斑直径约 38 μm，而真实 Mark 可能只有有限数量的条纹区域。

如果要直接计算有限尺寸 Mark 在实际光斑下的散射，就需要改变模型：

| | 周期 AH53 验证 | 有限尺寸 Mark |
|---|---|---|
| X 边界 | Periodic | 通常 PML |
| 光源 | 平面波 | 有限光斑，如 Gaussian 或角谱定义的聚焦光 |
| 计算域 | 16 μm 单元 | 覆盖完整光斑和结构并留缓冲区域 |
| 远场 | 离散衍射级 | 连续角谱，可能出现展宽和旁瓣 |
| 计算量 | 较低 | 更高 |

尤其不能简单地在 16 μm Periodic 计算域中放一个 38 μm Gaussian 光斑，就认为得到了单个有限 Mark 的真实照明结果，因为边界会周期性复制整个光源。

所以，**第一阶段一定要先完成严格周期模型的 RCWA/FDTD 对比，不要直接加入 38 μm 光斑和真实扫描过程。**

## 六、我建议怎样验证 FDTD 仿真是否正确？

最好分三个层次逐步检查。

**第一层：验证基础物理与能量守恒**

先移除全部条纹，只保留空气与折射率 1.5 的平坦衬底。法向入射的 Fresnel 反射率应为：

\[
R=\left(\frac{1-1.5}{1+1.5}\right)^2=0.04
\]

也就是约 4% 反射、96% 透射，且只有零阶传播光。

**第二层：验证周期 AH53 的衍射结果**

加入三条条纹，分别进行 s、p 仿真。将 FDTD 与 RCWA 的总 R/T、各阶 \(R_m\)、\(|r_m|\) 和 \(\arg(r_m)\) 对比。

建议将显著非零衍射级的功率相对差异先控制在 5% 以内，再针对关键阶次把复振幅与相位误差进一步降低。相位测试应避开振幅接近零的阶次，因为它们的相位数值不稳定。

**第三层：验证 Mark 位移对应的相位变化**

将三条条纹整体沿 X 平移 100 nm，比较位移前后各阶复振幅的相位。

根据周期结构的平移性质：

\[
r_m(\Delta x)=r_m(0)e^{\pm i2\pi m\Delta x/P}
\]

正负号取决于坐标与相位约定，而幅度不应发生变化。

对于 AH53，若将 16 μm 作为母周期，100 nm 位移导致的 ±1 阶相对相位变化绝对值为：

\[
|\Delta\phi_{+1,-1}|=
\frac{4\pi(0.1)}{16}=\boxed{4.5^\circ}
\]

如果比较 ±5 阶：

\[
|\Delta\phi_{+5,-5}|=
\frac{4\pi(5)(0.1)}{16}=\boxed{22.5^\circ}
\]

这也解释了为什么你的 AH53 中，必须区分母周期衍射级与子光栅衍射方向。

## 七、针对你现在的项目，最合适的实施顺序

我建议暂时不要直接把 FDTD 用于全部真实工艺形貌，而是先做一套标准 AH53 验证模型。

### AH53 FDTD 验证路线

1. **建立相同的二维结构**

   复制 RCWA 的材料、三条光栅、层叠及 16 μm 母周期。

2. **设置并验证光源、边界与监视器**

   使用平面波，X 周期边界、Y PML，先用平坦衬底验证 R/T。

3. **比较所有传播衍射级的功率**

   确定 `grating()`、`gratingn()` 和 `gratingangle()` 的结果正确。

4. **建立完整复 Jones 系数提取程序**

   从反射频域电场提取各阶复数系数，并统一 RCWA/FDTD 的归一化、偏振基底和相位参考。

5. **做数值收敛与位移实验**

   改变网格、PML、监视器位置及仿真时间，最后验证 100 nm 位移对应的相位变化。

6. **再引入实际 Mark 的不规则形貌**

   加入侧壁角、CD 不均匀、圆角、LER 等，最终扩展到有限尺寸与有限光斑模型。

**总结：** 对于目前的 AH53 二维规则结构，FDTD 的计算规模是可控的，几何建模并不是主要困难。真正需要投入精力的，是网格和边界收敛验证，以及将 FDTD 的频域电场正确转化为与 RCWA 定义一致的各阶复 Jones 系数。

只要这部分验证成功，你后续使用 Meep 等开源 FDTD 求解器时，就可以采用同样的物理测试和数据接口来判断其计算是否正确，而不必依赖 Lumerical 特有的 `gratingvector()` 作为唯一提取手段。

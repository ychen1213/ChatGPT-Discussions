# 第一轮：LSF 能否参数化构造侧壁角、Footing 与不规则薄膜？

## 用户提问（原文）

> lumerical的lsf脚本能做到添加 侧壁角 非水平薄膜 footing 侧壁不均匀 等效果吗

## 回答

**可以。Lumerical FDTD 的 LSF 脚本完全可以建立带有侧壁角（Sidewall Angle）、非水平薄膜、Footing（底部扩展）以及侧壁不均匀性的 Mark 结构。** 而且对于我们目前的 AH53 Mark 仿真，这些非理想形貌都可以设计成参数，通过修改参数自动生成不同结构并批量仿真。

不过，需要区分两种情况：

1. **二维截面形貌不规则**：例如侧壁倾斜、弯曲、底部 Footing、薄膜表面起伏。使用 addpoly 就可以实现，比较简单。
2. **真实三维形貌不规则**：例如光栅侧壁沿条纹长度方向不断变化，具有 LER/LWR、局部缺陷和随机粗糙度。需要使用三维几何建模，例如 addplanarsolid 或导入 STL。

### 1. 各种非理想形貌能否通过 LSF 实现？

| 非理想形貌 | LSF 能否实现 | 推荐方法 |
|---|---|---|
| 侧壁角（SWA） | 可以 | addpoly / Layer Builder |
| 左右侧壁角不同 | 可以 | addpoly |
| Footing（底部扩展） | 可以 | 自定义多边形 |
| Taper、顶部收缩 | 可以 | addpoly |
| 顶部或底部圆角 | 可以 | 多顶点拟合曲线 |
| 非水平薄膜、表面起伏 | 可以 | 多边形界面 |
| 共形薄膜、局部厚度变化 | 可以 | 两组界面轮廓 |
| 沿高度变化的侧壁曲率 | 可以 | 多顶点截面 |
| 沿条纹长度变化的侧壁 | 可以 | addplanarsolid / STL |
| 随机 LER/LWR、三维粗糙度 | 可以 | 三维表面网格与随机函数 |
| SEM/TEM 重建的真实形貌 | 可以 | 参数化重建或 STL/体素导入 |

这些并非都存在一个直接设置的属性。例如 Footing 并没有一个通用的 “footing = 30 nm” 开关，但我们可以用参数计算几何顶点，从而精确控制它。

Ansys 官方文档支持多边形顶点编辑、Planar Solid 自定义三维几何和 Layer Builder 侧壁角设置。参见下文的官方资料。

### 2. 对于我们目前的 XY 二维 FDTD，最方便的是 addpoly

我们的坐标约定是：

- X：Mark 周期方向。
- Y：膜层厚度及光入射方向。
- Z：光栅条纹长度方向。

addpoly 在 XY 平面定义截面轮廓，再沿 Z 挤出，非常适合现在的二维模型。

**图示转写：**二维 XY 截面中，Sidewall Angle 表现为倾斜直线侧壁；侧壁曲率可以用多个截面点逼近弯曲轮廓；Footing 是底部局部横向扩宽。三者都能用不同的多边形顶点描述。示意不代表真实 AH53 尺寸。

在这种建模方法下，LSF 不需要理解什么是 Footing 或侧壁弯曲，只需要根据我们给出的顶点坐标，生成对应的材料区域即可。

### 3. 一个针对 AH53 的 LSF 参数化示例

下面示例在已有 FDTD 工程的 Layout 中添加以下几何：

- 3 条间距为 3.2 μm 的光栅。
- 光栅顶部 CD 为 1.6 μm，高度 300 nm。
- 85° 侧壁角。
- 每侧 60 nm Footing。
- 左右不完全相同的弯曲侧壁。
- 厚度随 X 变化的非水平薄膜。

代码使用基础 LSF 命令编写，按 **Lumerical 2023 R2.1** 的接口考虑；尚未在该版本实机执行。

~~~javascript
# AH53 non-ideal geometry example
# X: periodic direction
# Y: vertical direction
# Z: stripe direction

switchtolayout;

L = 16e-6;
p = 3.2e-6;
cd_top = 1.6e-6;
h = 300e-9;

# Sidewall and footing
swa = 85*pi/180;
d = h/tan(swa);
foot = 60e-9;
foot_h = 30e-9;

# Non-flat film
tfilm = 100e-9;
wave_amp = 10e-9;
N = 81;

vf = matrix(N+2,2);

vf(1,1) = -L/2;
vf(1,2) = 0;
vf(2,1) = L/2;
vf(2,2) = 0;

for (j=1:N) {
    xx = L/2-(j-1)*L/(N-1);
    vf(j+2,1) = xx;
    vf(j+2,2) = tfilm+wave_amp*cos(2*pi*xx/L);
}

addpoly;
set("name","nonflat_film");
set("vertices",vf);
set("z span",1e-6);
set("material","<Object defined dielectric>");
set("index",1.46);

# Three non-ideal ridges
for (i=1:3) {

    xc = (i-2)*p;

    profile = [
        -cd_top/2-d-foot,        0;
         cd_top/2+d+foot,        0;
         cd_top/2+d+foot/2, foot_h/2;
         cd_top/2+d,        foot_h;
         cd_top/2+d/2+10e-9, h/2;
         cd_top/2,               h;
        -cd_top/2,               h;
        -cd_top/2-d/2+15e-9, h/2;
        -cd_top/2-d,        foot_h;
        -cd_top/2-d-foot/2, foot_h/2
    ];

    V = matrix(10,2);

    for (j=1:10) {
        xx = xc+profile(j,1);

        V(j,1) = xx;
        V(j,2) = tfilm
               + wave_amp*cos(2*pi*xx/L)
               + profile(j,2);
    }

    addpoly;
    set("name","ridge_"+num2str(i));
    set("vertices",V);
    set("z span",1e-6);
    set("material","<Object defined dielectric>");
    set("index",3.5);
}
~~~

这是**几何生成示例**，没有重建完整衬底、光源和监视器，也没有运行求解器。示例折射率只是用于显示不同区域，不能用来代替实际 Si/SiO₂ 的材料数据。运行前应清除旧版对应几何，避免重复叠加。

对于这里的 85° 侧壁角：

$$
d=\frac{h}{\tan85^\circ}\approx26.25\ \mathrm{nm}
$$

所以如果 1.6 μm 是顶部 CD，不计 Footing 时，底部 CD 约为 1.6525 μm。Footing 又进一步向外扩展了底部。

修改 swa、foot、wave_amp 和轮廓中的偏移量，就可以建立控制变量实验。

需要特别注意，脚本中的薄膜是**周期性起伏薄膜**，这样 X 两端的形貌连续，可以与周期边界配合。若改成从左至右持续倾斜且两端高度不同的薄膜，就不能直接使用原来 16 μm 单胞的周期边界。

此外，共形薄膜如果要求沿界面法线等厚，就必须计算轮廓法向偏移，不能简单地把所有顶点的 Y 坐标增加相同数值。

### 4. 对于真实三维侧壁不均匀，该怎么做？

这是和当前二维模型最重要的区别。

假设一条光栅沿 Z 延伸，侧壁位置由以下函数描述：

$$
x_L(y,z)=x_{L,0}(y)+\delta_L(y,z)
$$

$$
x_R(y,z)=x_{R,0}(y)+\delta_R(y,z)
$$

其中 $x_{L,0}(y)$、$x_{R,0}(y)$ 定义理想或平均截面，$\delta_L,\delta_R$ 则描述不同高度和不同 Z 位置的偏差。

- 如果偏差只与 Y 有关，二维 addpoly 就足够。
- 如果偏差也随 Z 变化，需要三维表面或实体几何。
- 如果已经获得 SEMulator3D 的 VDATA，或从中转换出 STL，可以保留真实形貌信息，而不必重新人为构造粗糙度。

Lumerical 的 addplanarsolid(vtx,fct) 允许通过三维顶点和表面面片建立任意多面体；stlimport() 则允许导入外部三角面网格。

### 5. 实际仿真还需要注意三点

**第一，创建了形貌不等于准确模拟了形貌。**例如加入 10 nm 的侧壁起伏，但使用 20 nm 网格，并不能保证求解器准确反映这项特征。必须检查实际材料网格，并做局部网格收敛测试。如果多个材料对象相互重叠，也应检查 mesh order，否则最终参与求解的材料区域可能与 CAD 视图中的预期不同。

**第二，二维模型无法描述沿 Z 方向变化的真实粗糙度。**在当前法向入射、各向同性材料且 Z 完全均匀的模型中，s、p 偏振解耦，交叉偏振系数理论上为零。要研究真实三维形貌导致的偏振耦合，需要进行三维求解。

**第三，Layer Builder 不一定是当前坐标系最合适的工具。**它确实能够直接设置侧壁角，但官方文档明确说明它沿 Z 方向堆叠层，且对象本身只支持绕 Z 旋转。而我们的膜厚方向是 Y，所以现阶段直接使用 addpoly 更自然。另外，Layer Builder 的侧壁角算法在 2024 R2 才获得进一步增强，不应默认 2023 R2.1 已具备该改进。

### 对我们课题的建议

我认为可以把形貌仿真分成两个阶段。

**第一阶段：参数化非理想 Mark。**使用 LSF 直接控制 CD、侧壁角、Footing、圆角、非水平薄膜和非对称侧壁。这样便于做单变量扫描，研究形貌变化如何影响不同衍射级的复振幅、相位及反射效率。

**第二阶段：真实三维 Mark。**对 SEM/TEM 重建或 VDATA 导出的三维结构，优先使用现有导入接口，而不是在 LSF 中用成千上万个简单几何体去拼接。把真实形貌和第一阶段的参数化模型进行比较，还可以识别哪些几何参数真正主导 alignment 信号误差。

因此，**我们当前二维 AH53 阶段的这些非理想形貌，基本不需要另外开发几何引擎，LSF 本身已经足够。**真正值得开发的是一个参数化形貌生成与管理模块，它能够统一记录形貌参数、生成几何、自动仿真，再将形貌变化和衍射复振幅变化对应起来。

# 第二轮：非理想形貌如何验证？Conformal Mesh 与网格收敛

## 用户提问（原文）

> 第一阶段：参数化非理想 Mark。 使用 LSF 直接控制 CD、侧壁角、Footing、圆角、非水平薄膜和非对称侧壁。这样便于做单变量扫描，研究形貌变化如何影响不同衍射级的复振幅、相位及反射效率。 在这个阶段 我该怎么确定我的仿真没问题呢 因为变成非理想情况之后感觉存在斜面 网格就是一个大问题 这是不是和lumerical的mesh设置中的共型有关

## 回答

你的判断是对的。**非理想 Mark 引入的斜面、圆角、Footing 和薄膜起伏，确实会使 FDTD 的网格离散成为重要误差来源。Lumerical 的 Conformal Mesh（共形网格）正是为改善这类材料界面的计算精度而设计的。**

但我建议把这个问题分成三个层次：

1. **几何是否正确？** LSF 建立的侧壁角、Footing、膜层形貌是否与设定值一致？
2. **离散是否正确？** 有限网格能否准确描述这些界面？共形网格是否真正改善计算？
3. **电磁结果是否可信？** 各阶反射率、复振幅和相位是否收敛，并满足已知物理规律？

这三个问题需要分别验证。不能仅凭 Lumerical 成功运行、场分布图正常，或者与 RCWA 的反射率接近，就认定模型正确。

## 一、为什么斜面会引起网格误差？

### 1. FDTD 的网格本质上仍然是矩形

以我们现在的二维 XY 模型为例，FDTD 使用 Yee 网格，电场、磁场分量交错分布在矩形网格上。

假设一个 85° 侧壁的真实界面是一条直斜线。如果采用传统 Staircase（阶梯网格），求解器只能根据网格采样位置决定使用哪一种材料，斜线因此会被离散成阶梯。

**原图转写：**Staircase 将斜面按矩形格点近似成阶梯；Conformal 仍用矩形 Yee 网格，但在穿越界面的单元内部考虑界面的位置和方向。不能把共形方法理解成求解器生成了贴着斜面的弯曲网格。

这里容易产生一个误解：

**Lumerical 的 Conformal Mesh 并不是把矩形 Yee 网格变成沿斜面弯曲的网格。**

它仍使用笛卡尔网格，但对于穿过材料界面的网格单元，采用更准确的界面电磁处理，考虑界面在单元内部的位置和方向，而不只是简单指定单一材料。

因此，共形处理可能使一个比较粗的网格仍具有较好的界面计算精度。

这就是 Ansys 所说的 *sub-cell accuracy*（亚网格单元精度）。

### 2. 为什么我们的 AH53 特别需要考虑这个问题？

假设光栅高度为 300 nm，侧壁角从 90° 变为 85°（这里角度以水平底面为基准）：

$$
d=\frac{300}{\tan85^\circ}\approx26.25\ \mathrm{nm}
$$

也就是说，单侧顶部到底部会产生约 26 nm 的横向变化。

当横向网格步长为 20 nm 时，26 nm 的总横向变化只相当于约 1.3 个网格步长。传统阶梯处理可能明显改变等效侧壁形貌。

改用 5 nm 网格后，横向变化约跨越 5.3 个网格步长，几何离散更细，但计算成本也增加。

因此：

- **共形网格负责提高界面处理精度。**
- **网格加密负责减少有限空间采样误差。**
- **收敛测试负责证明选用的组合已经足够准确。**

三者是配合关系，而不是互相替代。

Ansys 官方也明确建议：对于具有重要界面的结构，经常需要结合 Conformal Mesh 和局部 Mesh Override，而不是只依赖其中之一。

## 二、Conformal Mesh 应该怎么设置？

在 Lumerical FDTD 的 Simulation Region → Mesh settings 中，可以找到 Mesh Refinement 选项。

对于我们的课题，建议首先使用 **Conformal Variant 0**，但不同选项需要根据材料区分。

| 选项 | 工作方式 | 对我们课题的建议 |
|---|---|---|
| Staircase | 每个 Yee 网格采样位置采用单一材料，不考虑单元内的斜界面 | 作为对照组 |
| Conformal Variant 0 | 对通常的介质界面进行共形处理，不对金属、PEC 界面使用 CMT | **优先采用** |
| Conformal Variant 1 | 对包含金属在内的界面进行共形处理 | 金属 Mark 单独验证 |
| Conformal Variant 2 | 普通界面使用 CMT，金属/PEC 界面使用 Yu–Mittra 方法 | 特殊对照测试 |

Ansys 官方推荐多数模型首先使用 Variant 0。对于金属材料，Variant 1 虽然可能提高精度，但也可能在粗网格下引入非物理谐振，不能默认认为 Variant 1 比 Variant 0 更准确。

这里有一个容易忽略的限制：

**如果一个网格单元内同时包含超过两种材料，Lumerical 的共形处理会退回 Staircase 方法。**

比如在 Footing、衬底和共形包覆薄膜的交汇处，可能出现三材料交点。这时仅仅打开 Conformal Variant 0 并不能解决所有问题，必要时仍需要局部加密。

官方还提出两个实用条件：薄膜厚度通常至少要有两个网格单元覆盖；狭缝宽度最好不小于两个网格步长。

## 三、怎样确定 Mesh 到底够不够细？

这里需要做的是 **Mesh Convergence Test（网格收敛测试）**。

它不是单纯把 Mesh Accuracy 从 2 改成 5，然后看图片是否更清晰，而是固定物理模型，系统减小网格尺寸，检查最终关心的物理输出是否趋于稳定。

### 1. 先选择一个非理想结构测试

不建议一开始就对所有参数扫描。先选择一个代表性的结构：

| 项目 | AH53 代表性验证模型 |
|---|---|
| 母周期 | 16 μm |
| 入射波长 | 643 nm |
| 顶部 CD | 1.6 μm |
| 光栅高度 | 300 nm |
| 侧壁角 | 85° |
| Footing | 60 nm 横向延伸 |

沿用 XY 二维截面，X 周期，Y 方向 PML，光沿 −Y 入射。材料必须使用同一套光学常数与拟合设置。这里的 85° 和 60 nm 是验证用示例参数。

先不加入圆角、随机粗糙度和复杂薄膜，以便把侧壁相关误差单独分析清楚。

### 2. 使用不同尺寸的局部网格

建议先尝试下面这组网格。它们是收敛实验的起始点，不是已经验证过的最优设置。

| 组别 | 局部 Δx、Δy | 用途 |
|---|---|---|
| A | 20 nm | 粗网格，对照 |
| B | 10 nm | 初步加密 |
| C | 5 nm | 精细网格 |
| D | 2.5 nm | 参考计算，资源允许时进行 |

首轮都使用 Conformal Variant 0。如果资源允许，再对其中的 10、5、2.5 nm 增加 Staircase 对照。

注意，这里的 Δx、Δy 是 Mark 附近局部网格的最大步长，不是要求把整个 FDTD 区域都设置为 2.5 nm。

我们可以通过 LSF 创建 Mesh Override：

~~~javascript
# 在已有 AH53 FDTD 工程的 Layout 中执行
switchtolayout;

addmesh;
set("name","mark_local_mesh");

# 根据实际Mark位置调整
set("x",0);
set("x span",16e-6);

set("y",0.2e-6);
set("y span",0.6e-6);

set("set maximum mesh step",1);

set("override x mesh",1);
set("override y mesh",1);

set("dx",10e-9);
set("dy",10e-9);
~~~

这段脚本是局部网格示例，假设非理想形貌大致位于 Y = 0 附近。它不会自动设置全局 Conformal Variant；应另外在 FDTD Mesh settings 中确认该选项。已有同名 Mesh Override 时先更新或删除旧对象，避免重复创建。

上述 addmesh、dx、dy 等是官方支持的基本命令。

还有两点要注意：

- Mesh Override 设置的是最大网格步长，**最终实际生成的网格必须再次确认**，不能认为一定处处等于 10 nm。
- FDTD 全局的 Min mesh step 会限制允许生成的最小单元。如果它大于我们想使用的细网格，可能阻止局部加密。

### 3. 检查实际生成的网格，而不是只看 CAD 图

Lumerical 可以直接查看网格。

在 Layout 中点击 **View simulation mesh**，并用 F5（Recalculate simulation mesh）重新计算。然后放大斜面、Footing、薄膜交界的位置。

如果需要精确记录网格点，可以读取 FDTD 的 x、y 网格坐标，或通过监视器输出位置坐标。Ansys 有专门的操作说明。

更进一步，推荐增加一个 **Refractive Index Monitor（折射率监视器）**。

这里要区分两种结果：

- index preview：适合快速检查基本几何，但忽略部分共形网格信息。
- index / index_detail：可用于检查更接近真实求解器使用的材料离散数据。

如果要记录共形处理的影响，应按官方说明使用合适的 Spatial Interpolation 设置（Nearest Mesh Cell 或 None），开启 Record Conformal Mesh，并确保没有空间降采样。

不过，检查折射率图只能证明几何和材料映射大体正确，**不能代替电磁计算结果的收敛检验**。

## 四、怎么判断各阶复振幅和相位已经收敛？

这才是我们的课题中最重要的部分。

假设我们对某一衍射级得到复反射系数：

$$
r_m=|r_m|e^{i\phi_m}
$$

改变网格尺寸后，应该同时比较复振幅的模和相位，而不是只比较反射率。

### 1. 建议的三类核心指标

| 指标 | 检查什么 | 为什么重要 |
|---|---|---|
| $R_m$ | 各阶反射功率效率 | 判断能量分布是否收敛 |
| $r_m$ | 复反射振幅，包括实部和虚部 | 判断输出电磁场是否收敛 |
| $\phi_{+1}-\phi_{-1}$ | ±1 阶相对相位 | 直接关系到后续位移解调 |

例如，取 2.5 nm 的计算结果作为当前最细网格参考，检查其他网格结果与它的差异。

复系数相对误差可以定义为：

$$
\epsilon_r(h)=
\frac{|r_m(h)-r_m(h_{\rm ref})|}
{|r_m(h_{\rm ref})|}
$$

前提是参考阶次的复振幅不接近零。对于很弱的阶次，应改为绝对误差或采用固定归一化尺度，否则相对误差和相位本身都会变得不稳定。

相位误差可以利用：

$$
\epsilon_\phi(h)=
\left|\arg\left[r_m(h)r_m^*(h_{\rm ref})\right]\right|
$$

来避免简单相减造成的 $2\pi$ 跳变问题。

### 2. 对我们来说，相位应该有多高精度？

在理想周期光栅平移情况下：

$$
|\Delta\phi_{+1,-1}|=
\frac{4\pi|\Delta x|}{\Lambda}
$$

对 AH53 的 16 μm 母周期：

- 1 nm 位移引起的理想 ±1 阶相对相位变化为 **0.045°**。
- 0.1° 相位误差对应约 **2.22 nm** 的理想位移量级。

这说明：如果要将数值相位误差控制在相当于 1 nm 位移以内，理想 ±1 阶相位误差就需要小于约 0.045°。

这不是所有测量光路的通用指标。实际 SMASH 信号包含不同阶次及光路的组合，需要根据最终信号的位移灵敏度重新制定误差预算。

因此，我建议在初期设置一套临时验收目标：

- 主要强衍射级的功率随网格进一步加密变化小于约 1%。
- 主要复反射系数随网格进一步加密变化小于约 1%。
- 重点检查的相对相位变化小于 0.05°，如果位移精度目标更严格则相应收紧。

上述指标是**建议的工程筛选门槛，不是官方标准，也不是软件已经达到的精度**。另外，网格收敛误差并不等于总数值误差，参考网格本身仍可能存在误差。

特别要提醒：你之前的 **6 μm 光栅**平移 100 nm，理论上会出现 ±1 阶分别约 6°、相对约 12° 的变化；而换成 **16 μm 母周期**以后，理论上应变为每阶约 2.25°、相对约 4.5°。不要将这两个模型的验收数值混用。

另外，Lumerical 的 gratingvector() 会对所有传播级次的向量强度进行归一化，所以不能直接用它的模平方充当绝对反射效率。需要单独保存各阶功率和正确归一化的复反射系数。

## 五、除了网格收敛，还需要做哪些物理验证？

即使网格结果看起来收敛，我仍建议做以下几项独立测试，因为它们分别检测不同类型的错误。

### 验证 A：平面薄膜与解析解对照

先把光栅删除，只保留平面膜层。与 Fresnel 公式或多层膜传输矩阵计算比较 R、T 和复反射相位。

这一步用于排除材料、膜厚、源及监视器设置本身的错误。

### 验证 B：非理想光栅与 RCWA 交叉验证

分别计算矩形、梯形、带 Footing 的结构。对 RCWA 做 Fourier 阶数及几何分层收敛，对 FDTD 做网格和时间收敛。

两个独立算法在足够严格的设置下趋于一致，是很有价值的证据。但 RCWA 也有截断误差，并不是天然的绝对真值。

### 验证 C：刚体平移与相位定理

将整个周期光栅横向移动，例如 13、37、100 nm，保持物理形貌不变。理论上，衍射功率不变，而各阶复振幅按照已知相位因子变化。

这个测试尤其适合发现网格对几何位置的锁定误差。可以去掉预期的平移相位，再观察残余复振幅变化。

### 验证 D：对称性、偏振与能量守恒

对横向镜像对称的结构，在正入射、相应对称条件下，检查 ±m 阶功率是否相等。

对二维 Z 均匀、各向同性模型，s、p 偏振理论上解耦，交叉偏振应该为零。

无吸收系统检查 $R+T\approx1$；有吸收系统则检查 $R+T+A\approx1$。所有通量必须采用一致的入射功率和方向约定。

### 验证 E：时间、边界和监视器稳定性

固定网格，延长最大仿真时间、降低 Auto Shutoff 阈值、改变 Y 方向 PML 与结构的距离和 PML 层数。

同时检查反射监视器位置、光源注入误差和参考面处理，确保相位变化不是这些设置引入的。

Ansys 的官方收敛教程特别强调：FDTD 误差并不只有网格，还包括 PML 反射、材料拟合、数值色散、源注入和监视器插值。因此，所有参数都同时修改，不利于找到误差来源。

## 六、最终建议的实验顺序

我建议不要马上进行几十组 Sidewall Angle 或 Footing 扫描。先建立一套可靠的基准，再逐渐增加几何复杂度。

| 阶段 | 结构 | 核心验收 |
|---|---|---|
| 1 | 平面膜层 | 与 Fresnel/传输矩阵一致 |
| 2 | 理想矩形 AH53 | 与 RCWA 一致；能量、相位、平移规律正确 |
| 3 | 对称梯形 AH53 | Staircase 与 Conformal 的网格收敛对照 |
| 4 | 非对称侧壁 AH53 | ±m 阶功率及相位变化可信 |
| 5 | Footing、圆角 | 细小结构得到足够的局部网格分辨率 |
| 6 | 非水平、共形薄膜 | 膜厚、材料交界、周期边界正确 |
| 7 | 多参数扫描 | 使用前面确定的合格网格方案 |

有一点尤其重要：**不能因为 85° 侧壁角在 5 nm 网格下收敛，就直接认为 80°、88°、有 Footing、有圆角的所有结构都能使用同样网格。**应至少为每一类几何选择最苛刻的代表样本，重新验证一次。

如果后续要扫描很小的参数变化，例如 CD 每次增加 2 nm，还应额外检查“结果变化是不是网格引起的”。可以对同一物理结构施加已知的亚网格平移，去掉理论相位变化，检查是否出现不合理的振荡。

## 七、这对我们以后使用 Meep 和 FDTDX 有什么启示？

这实际上也说明了之前开源 FDTD 选型中一个很关键的问题：

Lumerical 的共形处理是提高界面精度的一种算法，并不只是 GUI 的便利功能。而开源求解器是否具有完全等价的界面处理、能否在较粗网格下达到同等准确度，需要用同一套非理想 Mark 的收敛实验来证明。

因此，这套验证流程以后可以直接复用到 Meep/FDTDX：

- 几何、材料和入射条件相同；
- 分别做空间与时间收敛；
- 统一衍射级复振幅与参考面；
- 比较达到同一误差门槛时的内存和运行时间。

这比在任意固定网格下直接比较两个软件的计算结果更有说服力。

**我的建议是先以“85° 梯形 AH53”建立第一套标准验证案例。**仅针对这一个模型完成 Staircase、Conformal Variant 0、10 nm、5 nm、2.5 nm 的交叉测试，重点观察 ±1 阶复振幅、相对相位以及更高强阶次的变化。

如果这一套测试通过，你就不仅知道软件“能够运行非理想形貌”，而且有证据说明：**在指定材料、几何和精度要求下，我们选择的网格与共形处理足以支撑后续 Mark 形貌敏感性研究。**

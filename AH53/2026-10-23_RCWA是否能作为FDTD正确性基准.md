# 讨论记录：RCWA 能否作为 FDTD 正确性基准

**用户：**

我可以认为RCWA算的是正确的吗  比如说让FDTD区对RCWA 对不上就是FDTD计算有问题

**助手：**

**可以把 RCWA 作为 FDTD 的基准（Benchmark），但不能直接认为 RCWA 一定正确，或者两者对不上就一定是 FDTD 出了问题。**

对于你目前的 AH53 Mark，我建议采用以下判断原则：

1. **理想、无限周期的 AH53：** RCWA 通常更适合作为参考解，因为它专门针对周期层状结构设计，通常能以较低计算成本得到高精度结果。
2. **RCWA 与 FDTD 对不上：** 优先检查 FDTD 的网格、PML、光源和数据提取方法，但不能立即判定 FDTD 算错。
3. **经过独立收敛验证的 RCWA 和 FDTD 仍对不上：** 要重点检查双方是否真正计算了同一个物理问题，以及复振幅定义和归一化是否一致。
4. **实际不规则、有限尺寸 Mark：** RCWA 的理想周期结果不能直接当作真实结构的正确答案。

关键区别是：**数值方法的理论适用性，不等于某次仿真结果的正确性。**

## 1. 为什么 RCWA 自身也可能算错？

RCWA 并不是保留了无限多个傅里叶模式，而是进行截断：

\[
E(x)=\sum_{m=-M}^{M}E_m e^{i2\pi mx/P}
\]

真实问题原则上需要无穷多个模式，实际计算只能保留有限个。

如果 \(M\) 不够大，结果就可能不准确。

对你的 AH53，母周期为 16 μm，波长为 643 nm。在法向入射条件下：

- 空气侧最多有 49 个可传播反射级（−24 至 +24）。
- 假设衬底折射率为 1.5，衬底侧最多有 75 个可传播透射级（−37 至 +37）。
- 计算还需要包含适量倏逝模式，才能准确表示光栅附近的电磁场耦合。

所以不能仅仅保留 49 个或 75 个模式，就认为结果一定收敛。

RCWA 在高折射率反差、金属结构及某些 TM 偏振问题中，还可能出现傅里叶展开收敛缓慢的问题。Li Fourier factorization 等方法正是为改善这一问题而发展的。<Cite refs={["turn939635search1","turn939635search6"]}/>

## 2. 怎样确认自己的 RCWA 结果足够正确？

最重要的方法是进行 **RCWA 收敛性测试（Convergence Test）**。

例如在你的二维 AH53 中，可以依次增加傅里叶模式数：

| 测试 | 模式总数（示例） | 观察结果 |
|---|---:|---|
| 1 | 101 | 记录各阶 \(R_m,r_m\) |
| 2 | 151 | 与 101 对比 |
| 3 | 201 | 与 151 对比 |
| 4 | 251 | 若仍未收敛，继续提高 |

这些数值是测试起点，而不是保证收敛的固定要求。

你需要分别比较：

\[
R_m^{(101)},R_m^{(151)},R_m^{(201)}
\]

以及：

\[
r_m^{(101)},r_m^{(151)},r_m^{(201)}
\]

假设某个关键阶次的结果如下（仅为说明方法的假设数据）：

| 模式数 | \(R_{+5}\) | \(\arg(r_{+5})\) |
|---|---:|---:|
| 101 | 0.1032 | 25.6° |
| 151 | 0.1051 | 25.2° |
| 201 | 0.1052 | 25.2° |
| 251 | 0.1052 | 25.2° |

那么可以认为该阶次在当前精度要求下已经收敛。

但要注意，某一个阶次收敛，不代表其他阶次一定收敛。还应检查总反射、总透射和其他关键阶次。

Ansys 官方也明确建议通过增加 RCWA 的 k-vectors 数量验证收敛，而不是直接假定单次计算足够准确。<Cite ref="turn939635search0"/>

## 3. 如果 RCWA 收敛，而 FDTD 结果对不上，怎么办？

这时候可以优先排查 FDTD，但应根据偏差类型判断。

| 现象 | 优先排查的原因 |
|---|---|
| 总 R/T 差异大 | 模型几何、材料、边界条件、光源设置 |
| 总 R/T 一致，但各阶功率不同 | FDTD 网格、PML、衍射级提取 |
| 各阶功率一致，但复振幅模长不同 | 电场与功率归一化定义 |
| 模长一致，但相位不一致 | 参考面、坐标原点、偏振基底、相位约定 |
| s 偏振一致，p 偏振不一致 | 偏振设置、网格及 RCWA 傅里叶收敛 |
| 网格越细，FDTD 越接近 RCWA | 有力证据表明原 FDTD 存在离散误差 |
| FDTD 已收敛，但 RCWA 仍随模式数变化 | RCWA 的结果还不能作为可靠基准 |

特别是对于你要研究的 SMASH 信号，**不能仅以各阶功率是否一致判断 FDTD 是否正确**。因为最终干涉信号还依赖于各阶复振幅的相位。

## 4. 我建议采用的验证标准

对于初期的理想二维 AH53，你可以规定以下工程验收目标：

- RCWA：增加傅里叶模式数后，关键阶次的复振幅和相位基本不再变化。
- FDTD：减小网格、增加 PML 层数、延长仿真时间后，结果基本不再变化。
- 两者比较：显著非零级次的衍射功率相对差异先争取控制在 1% 以内。
- 相位比较：统一参考面后，关键级次的相位差异先争取控制在 1° 以内。

这里的 1% 和 1° 是建议的项目初期目标，不是普适的数值精度标准。

还有一个非常好的验证办法：先不用 AH53，而是用**平坦的空气/玻璃界面**。这种结构的 Fresnel 反射系数有解析解，可以让 RCWA 和 FDTD 分别与解析结果比较。这样就不会陷入两个数值软件互相验证、却不知道谁正确的问题。

## 5. 对你的课题，我更推荐这样的思路

```text
        解析解 / 物理守恒关系
          验证基础求解能力
                 ↓
          ┌──────┴──────┐
          ↓             ↓
        RCWA           FDTD
    傅里叶模式收敛    网格、PML、时间收敛
          └──────┬──────┘
                 ↓
       交叉验证：各阶复 Jones 矩阵
    统一几何、归一化和相位参考
                 ↓
     建立可信的 AH53 电磁仿真基准
```

我的建议是：**现阶段将经过收敛验证的 RCWA 作为你的主要参考求解器，FDTD 作为独立交叉验证工具。**

对于理想周期 AH53，如果两者的模型完全一致、RCWA 已经充分收敛，而 FDTD 还没有完成网格和边界收敛，那么优先怀疑 FDTD 是合理的。

但当两个求解器都已充分收敛却仍存在差异时，就不能再简单地认为 RCWA 正确。此时最值得检查的通常是结构等效性、材料参数、归一化方法和相位参考。

这样建立起来的验证体系，未来才有能力判断引入真实 SEM/TEM 形貌后的结果究竟是物理效应，还是求解器的数值误差。
